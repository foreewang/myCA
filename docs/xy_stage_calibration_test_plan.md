# 电机 1/2（XY 位移台）标定与分支功能测试方案

## 1. 本次标定基线

| 项目 | 标定值 |
| --- | ---: |
| 电机1 / X 从站 | 1 |
| 电机2 / Y 从站 | 2 |
| X pulses/mm | 65536 |
| Y pulses/mm | 131072 |
| X 物理硬限位 | -1369032 ～ 6525977 |
| Y 物理硬限位 | -1000000 ～ 9500000 |
| 共用 safety_margin | 131072 pulse |
| X 可执行安全范围 | -1237960 ～ 6394905 |
| Y 可执行安全范围 | -868928 ～ 9368928 |
| 交接点 | (5000000, 0) |

X 负向物理硬限位采用现场重新实测值 `-1369032` pulse。`safety_margin=131072` 等于 Y 轴 1 mm、X 轴 2 mm。物理硬限位保持实测值，不把安全余量混入 `x_min/x_max/y_min/y_max`。

四种板型的培养面内径和 A1 起始观测点（4x，画面右侧刚贴内径内壁）：

| 板型 | 内径（mm） | A1（pulse） |
| --- | ---: | ---: |
| 6-well | 34.28 | (6080350, 6594411) |
| 12-well | 22 | (5662008, 7486000) |
| 24-well | 15.28 | (6148740, 7867852) |
| 48-well | 10.43 | (5724092, 8349136) |

换孔使用 `well_step` 示教脉冲步长，不再使用 `well_diameter_mm + well_gap_mm`。内径只用于孔内扫描圆。示教点写在 `well_teach`：行末端、列末端用于均分步长，对角点只记录。

`well_step.col = (行末端 − A1) / (cols − 1)`，`well_step.row = (列末端 − A1) / (rows − 1)`，X/Y 分别计算并四舍五入到整数 pulse，再写入配置；程序不会从 `well_teach` 自动重算。

| 板型 | `well_step.col`：A1→A2（X,Y） | `well_step.row`：A1→B1（X,Y） |
| --- | ---: | ---: |
| 6-well | (-2559297,0) | (0,-5122320) |
| 12-well | (-1705623,0) | (36,-3432599) |
| 24-well | (-1263778,-2342) | (-24,-2545461) |
| 48-well | (-858166,0) | (0,-1732404) |

孔内扫描方向保持 `x_stage_sign_for_view_right=-1`、`y_stage_sign_for_view_down=-1`。换孔不再使用 `row_stage_sign` / `col_stage_sign`。

## 2. 部署包静态检查

部署支线不包含开发测试套件。在 `/opt/colony_system` 使用项目虚拟环境执行静态编译和配置校验：

```bash
cd /opt/colony_system
.venv/bin/python -m compileall -q workflow devices vision third_party
.venv/bin/python -m workflow.config_validator --plates config/plates.yaml --handoff config/handoff.yaml --camera config/camera.yaml --autofocus config/autofocus.yaml --objectives config/objectives.yaml
```

完整自动化回归应在 `improve` 开发支线执行；这里的检查只确认部署文件可导入且现场 YAML 通过校验，不能替代硬件验收。

## 3. 上电前检查

1. 清空运动区域，确认硬件急停可用，先用厂家软件低速点动。
2. 读取电机1/2当前位置，确认驱动器零点没有再次被重置；本项目没有自动 Homing。
3. 分别接近四个物理限位，但不要用程序反复撞限位；确认位置读数与本表一致后退回至少 2 mm。
4. 先装空载测试板，不使用有价值样品；物镜保持在不会碰撞的安全高度。

## 4. 方向和导程验收

以交接点 `(5000000, 0)` 为 A 点。首次执行时降低速度并让操作员手持急停。

X 轴 10 mm 往复：

```bash
.venv/bin/python tools/stage_reciprocation_accuracy.py --axis x --point-a-x 5000000 --point-a-y 0 --point-b-x 5655360 --point-b-y 0 --cycles 10 --warmup-cycles 1 --profile-vel 100000 --plate-type 24-well --execute
```

Y 轴 10 mm 往复：

```bash
.venv/bin/python tools/stage_reciprocation_accuracy.py --axis y --point-a-x 5000000 --point-a-y 0 --point-b-x 5000000 --point-b-y 1310720 --cycles 10 --warmup-cycles 1 --profile-vel 100000 --plate-type 24-well --execute
```

验收要求：

- X 正脉冲：培养板物理方向 A1→A2，画面特征向左。
- Y 正脉冲：培养板物理方向 B1→A1（Y 读数增大）。A 行到 B 行 Y 读数变小。视野向下对应 Y 减小。
- 实测 10 mm 行程与量具结果一致；误差阈值由现场精度要求确定，不能只用驱动器位置反馈代替量具结果。
- A→B→A 连续 10 次无撞限位、卡死、异常声响或丢步；CSV/JSON 结果保存在 `data/stage_accuracy`。

示教判据与 A1 相同：画面右侧刚贴该孔内径内壁。最远孔是 A1 + 行列步长的网格点。以“网格坐标减对角示教坐标”定义残差：12 孔 C4 为 (+3216,-3929) pulse，约 (+0.049,-0.030) mm；24 孔 D6 为 (+4358,-21926) pulse，约 (+0.066,-0.167) mm；48 孔 F8 为 (-1,0) pulse。6 孔对角与网格一致。24 孔 A6 的网格点为 (-170150,7856142)，相对行末端示教点为 (-2,+2) pulse，来自整数步长取整。残差需按现场业务容差验收。

若整组点出现相同偏差，重新标定该板 A1；若偏差随行/列累积，重新示教行末端/列末端并改 `well_step`，不能只修改单个孔坐标，也不能再用直径加间隙去凑孔距。

## 6. 扫描覆盖与安全验收

使用 `config/objectives.yaml` 的 4x FOV=3.22×3.22 mm、10x FOV=1.31×1.31 mm 和 `overlap=0.1`，逐板遍历全部孔做离线规划。扫描圆半径为 `内径/2 − 半视野`。X 安全范围为 `-1237960` ～ `6394905`，Y 安全范围为 `-868928` ～ `9368928`。配置校验和路径预检均通过，所有板型在两种物镜下的扫描点均无需裁剪；各板整板累计裁剪点数如下：

| 板型 | 4x 裁剪点数 | 10x 裁剪点数 |
| --- | ---: | ---: |
| 6-well | 0 | 0 |
| 12-well | 0 | 0 |
| 24-well | 0 | 0 |
| 48-well | 0 | 0 |

X 下沿最紧的是 6 孔板 10x 的 A3、B3，最小 X=-1198966，距 X 安全下限 38994 pulse（约 0.595 mm），距重新实测的物理硬限位 170066 pulse（约 2.595 mm）。`safety_margin` 保持 131072 pulse，全部原规划扫描点均可保留。

所有板型在两种物镜下的 Y 上沿余量约 4.24～6.68 mm；Y 下沿最紧的是 48 孔板 10x 末行，最小 Y=-776486，距安全下限约 0.705 mm（距硬限约 1.705 mm）。上述余量和裁剪结果只代表离线规划，现场仍需验收实际覆盖与运动。

起始点本身仍必须落在安全范围内，否则任务在规划阶段失败。

## 7. handoff 与回归验收

1. 空载执行 `load_in`、`unload_out`，两者均应到 `(5000000,0)`。
2. 将测试配置中的交接点临时改到安全范围外，任务必须在发运动指令前失败；测试后恢复配置。
3. 验证到位误差超过 `arrival_tolerance_pulse=3000` 时不会返回机器人 ready 状态。
4. 依次执行：单孔 4X 采集、跨孔 A1→A2→B1、视觉补偿、自动调焦、4X/10X 物镜切换、handoff。
5. 最后执行目标业务板型的整板任务；任何 `stage_limit_precheck` 失败都应先调整机械安装或重新标定，不绕过保护。
