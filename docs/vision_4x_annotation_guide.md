# 4× iPSC 克隆实例标注规范

## 1. 标注目标

- 任务：在 4× 原图中定位并分割每一个可见 iPSC 克隆。
- 类别：只能使用 `ipsc_clone`。
- 每个可见克隆必须对应一个独立 polygon 或 mask。
- 4×图像不标注“较高质量/较低质量”，质量判断留给10×模块。

## 2. 推荐工具

使用 CVAT 创建图像实例分割任务。上传原始 BMP，标签名称设为
`ipsc_clone`，标签形状可设为 `Any`，实际标注优先使用 Polygon；边缘特别
不规则或 Polygon 难以表达时使用 Brush Mask。

为 `ipsc_clone` 增加下列 Checkbox 属性，默认值均为 false：

- `truncated`：克隆被图像边界截断。
- `boundary_ambiguous`：4×下无法稳定区分边界或两个融合克隆。
- `exclude_from_training`：复核后仍无法确认是克隆的疑难目标。

## 3. 什么需要标

- 标注所有确定可见的克隆，不论其面积、亮暗、致密程度或所在质量目录。
- 沿克隆连续细胞团的外缘描边，包含连续的铺展边缘，不逐个描单细胞。
- 图像边缘只标可见部分，不推测图像以外的轮廓，并设置 `truncated=true`。
- 克隆内部被组织包围的亮区或纹理变化仍属于该克隆，不因亮度变化挖洞。

## 4. 什么不标

- 孤立单细胞和零散、互不连续的小细胞群。
- 碎屑、污染物、气泡、划痕、孔壁、暗弧、黑角和照明阴影。
- 仅由亮暗变化产生、没有可辨识细胞团结构的区域。

## 5. 相邻和融合克隆

- 两个克隆之间存在可重复辨认的间隙、低密度沟或独立外缘时，标成两个实例。
- 完全融合且4×下不存在可靠分界时，标成一个实例，并设置
  `boundary_ambiguous=true`。
- 不允许两个实例的 mask 大面积重叠；同一像素原则上只属于一个克隆。
- 不要为了增加实例数量而猜测不可见的分界线。

## 6. 空白图与难例

- 一张图经全图复核后确实没有克隆，应保留为负样本，不画任何形状，并在
  数据清单中标记 `complete_negative`。
- 含孔壁、暗角、碎屑但没有克隆的图是重要 hard negative，不能删除。
- `exclude_from_training=true` 的疑难实例先保留供复核，第一版训练时排除，
  不要强行转成正样本或负样本。

## 7. 标注操作顺序

1. 先以适合查看全局的缩放比例浏览整张图，记录所有疑似克隆位置。
2. 放大到能够辨认连续细胞团边缘，逐一使用 Polygon 或 Brush Mask 描边。
3. 从左上到右下复查，确保没有漏掉小克隆和图像边缘的截断克隆。
4. 隐藏原图只看 mask，检查实例是否粘连、重叠、破洞或漏出明显区域。
5. 再显示原图，检查孔壁、暗影和碎屑是否被误标。
6. 保存后由第二个人抽检；首批38张建议全部复核，而不是只抽样。

## 8. 导出和数据拆分

- 从 CVAT 导出 `COCO 1.0/1.1` 实例数据，并另存一份 CVAT 原生备份。
- 当前38张来自同一次采集，应使用同一个 `group_id`，不能随机拆到
  train/val/test；现阶段全部作为 train/pilot 数据。
- val 和 test 必须来自不同日期、培养批次或孔位的新采集数据。
- COCO 中每张图最终必须带有 `objective=4x`、`group_id`、`split`；每个实例
  必须有 `truncated` 布尔值。

## 9. 一致性验收

首批先由同一标注者完成5张，再由第二位复核者独立检查。只有下列规则一致
后再标剩余33张：

- 什么算克隆、什么算散落单细胞；
- 接触克隆何时拆分；
- 模糊边缘画到哪里；
- 图像边缘实例和孔壁干扰如何处理。

正式验收至少检查：实例是否漏标、非克隆是否误标、实例是否错误粘连、边界
是否明显偏移、`truncated` 是否正确。没有通过复核的标注不能进入训练集。
