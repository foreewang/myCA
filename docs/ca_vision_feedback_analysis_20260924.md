# CA 规则视觉误检、漏检原因分析

分析日期：2026-09-24。代码基线：`8e0199d1986ac8c1589f8539c2b8fbdc2b41d0bd`。

## 结论

当前规则算法存在“目标定义不完整”和“分割机制与样本不匹配”两层问题。主要原因是：大目标硬过滤、局部阈值漂移、暗区补偿偏向阴影/黑团、纹理桥接后整体丢弃，以及把分割有效直接当作可挑取。单独放宽面积阈值不能解决问题，在图 5 上会把下方暗区与左侧阴影作为可挑取目标。

本次完成代码审查、Word 六图离线复现和面积上限对照实验；未调整生产算法、运行配置或硬件。附件中的提问和答复作为分析资料使用，不作为执行指令。生物学判断均引用用户提供的反馈，未自行把黑色区域诊断为坏死。

## 根因与代码位置

### 1. 大目标在轮廓细化前被硬删除（已复现）

`vision/vision/texture_segment.py:67` 直接排除 `bbox_ratio > max_bbox_area_ratio`，默认值为 0.30。该比例计算的是外接矩形面积，并非克隆实际面积。图 1 明确认可的目标直接被删除，图 2 的大片也无法进入后续流程。

此外，粗检测中失败分支直接 `continue`，没有对每个被拒目标保存原因；`coarse_candidate_count` 统计的是筛后数量。现场看到“0 个候选”时不能知道是完全没提取到纹理，还是提取后被过滤。

### 2. 目标占比升高导致“背景”阈值升高，细化反而抹掉目标（已复现并有代码依据）

`vision/vision/preprocess.py:45`：

```python
interior_floor = max(noise_floor, percentile(std, 40) * 1.5)
support_floor = max(noise_floor, interior_floor * 1.5, threshold * .65)
```

当纹理覆盖视野较大比例时，第 40 百分位不再可靠代表背景；纹理越密，阈值也可能越高。粗分割和局部细化分别调用 `texture_signal`（`texture_segment.py:58`、`:124`），并各自重新估计背景。

图 1 的 `interior_floor` 从整图 15.34 升至左侧目标 ROI 的 23.89，对应支撑下限主要项从 23.01 升至 35.84；最终只保留 7.14% 的粗支撑。图 2 从 32.21 升至 ROI 的 40.07，最终保留 44.78%。这解释了为什么取消粗筛限制后仍漏检。

`MIN_RETAINED_SUPPORT_RATIO=0.50` 本身在阻止碎片冒充完整克隆。应修正前面的阈值/分割稳定性，而不是直接取消这一保护。

### 3. 暗区补偿同时放宽了“有纹理”的要求（已确认机制；图 5 对照出现错误保留）

`preprocess.py:58` 把低于整图平滑亮度中位数 45 的区域直接并入支撑；`:64` 对暗区的标准差做放大，使质量判断在暗区等价于使用基础 `noise_floor=1.5`，而其他区域仍使用自适应阈值。

这套机制原本用于保留低对比度的深色克隆，但也会支持阴影及有少量纹理的黑团。全图中位数不能可靠区分局部照明衰减和细胞本体的暗度。图 5 对照的错误保留正落在暗区/阴影，说明仅解除面积过滤会暴露这条路径的问题。

不能反向改成“所有暗区都拒绝”，否则与图 4 的反馈冲突。需要在克隆整体内部区分小暗斑、连续大黑团和低频照明阴影。

### 4. 稠密克隆与稀疏散点仅靠标准差不易区分，形态学会连接两者（图 6 已复现连接）

当前主要证据是 7×7 局部标准差及 21×21 密度平滑，再执行 7×7 闭运算、3×3 开运算。散点边缘同样具有高标准差，平滑和闭运算存在桥接风险。连接后的不规则整体再被外接框面积或 `solidity < .45` 删除，右上真实目标随之消失。

本次确认了连通后的结果，尚未通过逐项消融量化密度平滑与闭运算各自的贡献，不能只归罪于某一个核尺寸。

### 5. 几何有效不等于可挑取，且“纹理覆盖率”不等于纹理均一性（代码确定）

`vision/vision/detect_pipeline.py:202`：

```python
item["is_pickable"] = item.get("is_valid_for_compensation") is not False
```

当前没有单独表达“大型黑团不宜挑取”“小暗斑可容忍”“致密均一优先”等业务判据。`texture_coverage` 实际只是内部像素超过标准差阈值的比例，不是对细胞纹理均匀程度的评价。面积排序（`scorer.py`）也没有表达质量优先。

`tests/test_rule_dense_colonies.py:12` 将带轻微噪声的深色椭圆定义为应当保留的正样本；测试覆盖了分割能力，却不能验证图 3 的业务排除条件。应保留分割能力测试，同时补充独立的可挑取分类测试。

### 6. 像素参数没有物理尺度一致性，部分参数也未透传（代码确定；现场影响待原图核实）

`segment.py:12` 的 `min_area=10000` 是粗工作图中的固定像素面积。粗工作图最长边最多 1024，文档小图不放大；同一视野以不同分辨率提供时，面积门槛和 7/21 像素纹理窗口对应的物理尺度不同。不能把 Word 图调好的数值直接用于原始相机图。

若图像确实是完整 3.22 mm 视野，10000 像素面积在宽约 630 与 1024 的方形工作图上对应的等效圆直径约为 0.58 mm 与 0.35 mm；这是尺度差异示例，不是推荐挑取尺寸。文档嵌入图是否经过裁剪尚未核实。

`workflow/detect_api.py:22` 的 `rule_texture_kwargs` 没有透传 `max_bbox_area_ratio`；仅在任务配置里增加该键，并不能通过这条规则参数路径影响扫描与补拍。`min_area` 也未暴露于主检测函数。优化需同时检查算法入口、工作流配置和补拍路径。

## 建议优化顺序

1. **先增加可解释诊断和六图验收基准。** 保存每个候选的拒绝阶段、阈值、面积、支撑保留率和暗区比例；使用原始相机图补齐实例轮廓及可挑取标签。分别评价分割召回和挑取分类，避免用总检测数量衡量效果。
2. **修正背景估计和细化一致性。** 用目标外背景环带/可靠背景样本估计背景；背景不足时标记低可信度。粗、细阶段保持标定尺度和阈值口径可比，避免把 ROI 内的克隆重新当背景。先以图 1 恢复完整轮廓作为验证目标。
3. **改进支撑形成和连接处理。** 加入跨尺度纹理一致性、区域内部均一性及局部前景占有特征；检查窄桥，只拆分由稀疏连接串起来的区域。图 6 要保留右上块，图 2 的连续融合片仍应允许作为整体，不能无差别分水岭拆碎。
4. **将识别、分割可靠性、挑取适宜性分开。** 大面积不再作为唯一删除理由；暗区用局部背景归一化，评估最大暗斑相对面积、连续性及周边纹理，而非绝对灰度一刀切。小暗斑不否定整体；大黑团独立标记为不宜挑取，具体阈值需标注样本校准。
5. **最后统一尺寸/参数与工作流。** 按可靠 FOV 和输入尺寸换算实际面积、等效直径、窗口尺度，并打通扫描/补拍配置。没有反馈依据的尺寸区间和邻近距离不要加入硬过滤。

不建议把 `max_bbox_area_ratio` 直接统一改为 1.0、整体降低纹理阈值、关闭支撑保留率检查，或仅降低 `min_area`。这些动作分别已暴露或存在明确的暗区误保留、碎屑增多、残片被接受风险。
