# CA 规则识别优化方案：1.5 mm 克隆、孔边阴影与过度生长暗区

本方案基于六张反馈图、上一轮离线复现，以及用户补充的事实：优秀克隆可约为 1.5 mm；图中大范围阴影来自靠近孔边；局部细胞暗区为过度生长。本文是待实现方案，参数中的试验值尚未经过原始帧验证，不是已上线配置。

## 1. 尺寸过滤：物理面积与直径，替代外接框硬过滤

在完整 3.22×3.22 mm 视野中，近圆克隆的估算如下。文档图经过裁剪时不能直接采用此换算。

| 直径 | 圆面积 | 外接框占视野 | 1024 像素宽工作图中的直径 |
|---|---:|---:|---:|
| 1.0 mm | 0.785 mm² | 9.64% | 318 px |
| 1.5 mm | 1.767 mm² | 21.70% | 477 px |
| 1.8 mm | 2.545 mm² | 31.25% | 572 px |
| 2.0 mm | 3.142 mm² | 38.58% | 636 px |

现有 30% 外接框上限对应约 1.76 mm 的正方形边长。因此“1.5 mm”本身不会触发这一过滤，但不规则外形、分割扩张或连接阴影可使粗框超过上限。必须修复分割，而非只放宽上限。

新增物理量：`area_mm2`、`equivalent_diameter_mm`、`max_feret_mm`、`size_is_lower_bound`。等效直径为 `sqrt(4*area_mm2/pi)`；最长径从换算为毫米后的轮廓计算，不用单个 x 方向比例代替二维标定。截断目标的观测尺寸只作为下界。

建议参数语义：

| 参数 | 建议起点 | 作用与限制 |
|---|---|---|
| `max_bbox_area_ratio` | 新版支持 `null` | 取消仅凭外接框大而删除；大区域转入连接分析/复核，不自动放行挑取。 |
| `large_bbox_review_ratio` | 0.50，试验值 | 标记可能融合或串联的候选，优先检查，不是新硬上限。 |
| `max_equivalent_diameter_mm` | `null` | 不把 1.5 mm 误设为生物学最大值。 |
| `large_diameter_review_mm` | 2.0，试验值 | 超过后增加大目标复核标记，后续按标注调整；不直接删除。 |
| `min_area_mm2` | 尚无依据确定 | 用最小认可克隆标注确定。当前 10000 像素在 1024²、3.22 mm 视野约为 0.099 mm²，只可作为兼容对照，不能宣称为工艺下限。 |
| `reject_border_touch` | `false` | 图像边缘不等于孔壁；图 6 的边缘目标需保留。 |
| `min_retained_support_ratio` | 0.50，暂保留 | 检查细化是否塌缩；只对同实例、同可见区域的可靠支撑计算。 |
| `min_rotated_aspect_ratio` | 原 0.30 先作为形状复核信号 | 用孔壁/条带证据确认伪目标，避免仅因克隆不规则而丢弃。 |

以上新增语义必须实现后才生效。现有代码不能接收 `max_bbox_area_ratio=null`。在旧版上把值设为 1.0 只能用于离线定位，上一轮已在图 5 观察到暗区错误保留，不建议作为独立生产修复。

## 2. “粗分割支撑”是什么

粗框回答“目标大概在哪里”；粗分割支撑是框内一张二值图，回答“哪些像素被第一轮算法认为有前景证据”。当前由纹理标准差、纹理密度、暗区补偿和形态学共同形成，所以它是算法假设，不是真实细胞标注，也不一定可靠。

对应 `texture_segment.py` 中候选的 `_support_small`。细化时将其映射到 ROI 工作坐标得到 `reference`，计算：

```text
retained_support_ratio = 面积(最终轮廓掩膜 ∩ reference) / 面积(reference)
```

例如粗支撑有 10000 个像素，最终只覆盖其中 700 个，保留率为 7%。当前低于 50% 则视为细化塌缩，避免把一个大克隆的残片误当完整克隆。图 1 的 7.14% 正是这种情况，不代表细胞存活率或生长密度。

改进后记录原始与清理后的支撑。先剔除已确认孔壁/不可见区域、完成实例拆分，再为每个实例冻结可靠参考支撑；在统一坐标计算保留率。不能在细化失败后反过来缩小分母以使结果通过。若清理造成大量原始支撑丢失，应另外记录 `support_cleanup_ratio` 并复核。

## 3. 阴影与过度生长：两个独立层次

阴影是照明/可见性状态；过度生长是细胞区域状态。两者可能叠加在同一位置，不能只输出一个互斥的“黑色类别”。

| 证据 | 孔边阴影倾向 | 过度生长暗团倾向 |
|---|---|---|
| 空间位置 | 与已标定孔边的位置、方向吻合 | 可在孔内任意位置，也可处于阴影中 |
| 大尺度亮度 | 片状/带状缓变，常沿孔壁延伸 | 相对周围具有局部暗核 |
| 照明补偿后的残差 | 通常明显减弱 | 可靠补偿后仍明显偏暗 |
| 周边结构 | 不应单独形成克隆种子 | 与细胞纹理、克隆主体有空间联系 |
| 无法看清时 | 标为不可可靠评价 | 不强制解释为正常或过度生长 |

这些是组合判据，不是单条规则。接触图像边缘、灰度低、平滑或纹理强，任何一项单独都不足以完成区分。

### 3.1 孔边位置与照明模型

优先利用已有孔内径、扫描位置、视野标定、实际位移台位置和图像轴向映射，在图像中预测孔壁位置及置信度。项目的 `a1_start` 是孔侧观测起点，不是孔中心；禁止直接当圆心。使用现有坐标换算并用实际孔壁图验证方向、偏置和残差。

孔壁先验用于约束阴影模型，不直接删除整条固定宽度边缘带。图像裁切造成的边缘目标仍保留。

若已有同物镜、同曝光/照明条件的空孔参考，建立随孔内位置变化的照明场 `L(x,y)`，必要时结合暗场 `B(x,y)`。校正示意：

```text
I_corrected = (I - B) / max(L - B, epsilon) * reference_level
```

无参考时，在可靠背景、非黑团区域拟合平滑照明场，使用鲁棒拟合迭代排除细胞目标，并记录背景样本覆盖度。密集克隆占满视野时不强行拟合。不能直接把任意大核高斯模糊当背景，1.5 mm 大克隆可能被吸收为照明变化。

区分可校正弱阴影与低信噪/饱和黑区。限制校正增益；不可见区域进入 `unobservable_mask`，不通过强行提亮放大噪声。阴影带中校正后仍有可靠纹理的正常克隆可以保留。

### 3.2 过度生长暗区

在可信照明校正后提取局部暗残差，与周边背景/正常克隆参考比较，输出 `overgrowth_mask` 和置信度，不再使用原图“低于全图中位数 45”直接判断。

每个实例记录：总暗区面积比例、最大连续暗区面积/等效直径、暗区对比度、可用正常纹理比例。最大连续暗区用于区分大黑团与多个小暗斑；不能只用总暗像素比例。

暗区比例阈值应由图 3/4 及更多标注校准，必须同时检查暗区物理面积、强度和连通性，不能仅按比例判定。用户已明确：确认的过度生长大块暗区禁止挑取。独立大黑团标记 `overgrown` 且 `is_pickable=False`；同一克隆若含达到“大块过度生长”标准的区域，整体禁止自动挑取，不能仅挑它的正常一角来绕过判断。少量小暗斑不自动否定整个正常克隆；邻近但独立的正常克隆不受无条件连带否决；证据不足为 `review`。

## 4. 防止阴影、暗团、正常克隆合成一个实例

第一步删除现有无条件通道：

```python
support[dark_body] = 255
seed[dark_body & (std > noise_floor)] = 255
quality_std = np.where(dark_body, std * (interior_floor / noise_floor), std)
```

由照明校正后的纹理生成正常克隆种子和弱支撑；暗团建立单独候选。平滑阴影没有资格成为克隆种子。保留低对比真实克隆需要背景参照和多尺度纹理证据，不能靠“暗就补前景”。

第二步在统一物理尺度计算纹理与背景统计。粗阶段只估计一次可信背景模型，ROI 细化继承该模型；在 ROI 分辨率变化时换算窗口并验证噪声统计，不直接照搬不同尺度下的原始标准差阈值。禁止再次用被目标占据的 ROI 第 40 百分位估背景。

第三步先限制生长，再谈连接。去掉跨整个前景掩膜的固定闭运算；在同一种子/同一实例内部做小范围孔洞修补，设置可见背景缝隙、可靠孔壁及独立暗团的阻断区域。小暗斑可作为克隆内部子区域，不因其存在把克隆拆碎。

第四步只对确有多个独立种子、且存在背景谷/窄桥/类别分界的候选执行受约束拆分。可使用标记控制的分水岭或受限区域生长，不把每个纹理局部峰都当新克隆。图 2 的连续均一融合片允许维持一个实例。

闭运算含先膨胀再腐蚀，不能承担“确定两个区域属于同一克隆”的语义判断；标记控制的分水岭也需要可靠标记来降低过分割。[OpenCV 形态学文档](https://docs.opencv.org/4.13.0/d9/d61/tutorial_py_morphological_ops.html)、[OpenCV 分水岭文档](https://docs.opencv.org/4.12.0/d3/db4/tutorial_py_watershed.html)。上述实例策略是针对本项目的设计，尚未完成性能验证。

第五步分开保存外轮廓和可用内部掩膜。当前 `RETR_EXTERNAL` 后实心填充会丢失内部孔洞，因此即便正确找到外边界，也必须保留 `unobservable_mask` / `overgrowth_mask`。挑取点只能从可用区域产生，不能填回内部排除区。几何余量应由挑取工具尺寸和定位误差确定，不能把现有 1 px 当作已确认的物理挑取间距。

图 5 的期望结果：上方正常克隆独立保留；下方暗团作为过度生长区域单独记录；左侧孔边阴影归入照明/可见性层，不进入同一个细胞实例。若某处真实边界不可见，输出复核原因，不强制补出确定边界。

## 6. 实施与验收

分三个可独立检查的改动阶段实施：

1. 物理尺度/参数透传、分阶段诊断、取消大框静默删除，并建立原始图标注基线。此阶段不宣称已解决误检。
2. 阴影校正、暗区分离、粗细背景一致性和条件拆分；验证图 1/5/6 与图 2 的融合片保留。
3. 挑取质量分类、可用内部掩膜、工作流输出及跨视野一致性；验证图 3/4 和挑取结果导出。

必须覆盖的行为：

- 1.0、1.5、1.8、2.0 mm 的正常纹理目标，改变输入分辨率后毫米尺寸和分类基本一致；2.0 mm 只触发预设复核，不无声删除。
- 同一正常克隆置于孔中心及可校正孔边阴影，识别身份稳定；深黑不可见区不凭空补出细胞。
- 正常克隆邻近阴影和过度生长暗团，三者不合并；增加小暗斑时正常克隆仍保留。
- 图 1 左侧完整保留，图 5 上方保留/下方暗团排除挑取，图 6 右上保留且散点不批量成目标；图 2 连续片可维持整体。
- 被允许的窄桥拆分后保留率使用各实例固定参考；细化塌缩仍能被检测，不通过修改分母掩盖。
- 外轮廓填充、可视化、序列化后内部排除区仍不能成为挑取点；扫描与补拍使用同一判定。

六张图用于开发回归，还需要独立标注图像验证泛化；按正常克隆召回、错误挑取数、实例合并错误、轮廓完整性分别统计，不能只看总候选数量。当前只提交方案文档，未修改算法默认行为。

## 7. 跨图克隆与过度生长的全局判定（用户补充要求）

### 7.1 当前实现的缺口

- `workflow/platform_defaults.py` 的 `DEFAULT_SCAN_OVERLAP=0`。这是代码默认值，现场任务可覆盖；零重叠不能保证跨边界身份可由图像可靠确定。
- `clone_dedupe.py::_same_clone` 要求外接框交集/较小框面积 ≥0.50，且框中心距离 ≤0.10 mm。完整实例的重复观测适用，但同一大克隆的左右残片中心可相距很远；不能只放大中心阈值，否则容易合并两个相邻克隆。
- 现有 complete-link 聚类要求组内每一对图都满足同一身份条件。同一克隆跨三张图时，首尾图可能不相交，需要专门的跨边界实例关联，不应简单删除现有防串联保护。
- `assign_global_clone_ids` 使用代表图外接框，没有融合完整轮廓；还把各图定位点做加权平均，这个平均点不保证落在非凸克隆内或避开暗区。
- `pickable_result.py` 只要组内某张图 `is_pickable=True` 就可能导出；没有全局过度生长判定。这会遗漏“图 A 只看到正常部分，图 B 看到同一克隆的大块暗区”的情况。

### 7.2 新流程：单图保留证据，全局实例决定挑取

```text
单图照明分析/纹理分割/暗区识别
  → 保留完整目标、边缘残片、过度生长区域及其置信度
  → 根据实际位移台位置投影至孔坐标，并校验重叠区配准
  → 关联同一实例，合并可见轮廓与暗区证据
  → 判断覆盖完整性、是否过度生长及是否需要补拍
  → 全局质量通过后生成一个挑取记录
```

单图边缘残片标记 `truncated=True`、`size_is_lower_bound=True`、`needs_cross_view_resolution=True`，保留用于关联。边缘残片不套用完整目标最小面积/形状硬过滤，也不直接授权挑取；散点仍需基本纹理证据。

投影使用统一图像轴向、毫米/像素、实际台位和标定误差。重叠区域内以局部配准校正残差，只在配准可信时融合。对弱纹理、重复纹理和明显视差/畸变不强行配准；误差容限由重复拍摄残差标定，不能直接把配置 `calibrated` 改为 true 代替标定。

跨图匹配分两类：完整实例保留原有严格去重；截断实例新增“重叠区内掩膜对应 + 边缘轮廓延续 + 纹理一致性 + 空间误差约束”。只在图像共同可见范围比较，不要求两个残片的整体中心相同。多个关联可能冲突时保留待确认身份；三图链路用相邻视野一致性和全局几何检查，不把无约束传递合并当成正确实例。

融合轮廓面积按共同坐标中的并集计算，不能把每张图的面积相加；阴影、不可见区和暗区证据单独保留。重叠区暗分类有冲突时按可见性和校正可信度处理，不能简单平均灰度把黑团冲淡。

只有已经确认属于同一全局实例、且证据可靠的大块过度生长判定，才能将该实例设为 `rejected_overgrown`。独立邻居的暗团不传播否决。不能根据截断图中的暗区占比直接推断完整克隆的暗区比例；需融合或补拍后判断，但明确的大块暗团不能因其他图未拍到而被抹除。

全局状态建议为：`pending_views`、`needs_recapture`、`pickable`、`rejected_overgrown`、`review`。单图无权覆盖全局拒绝结果。

### 7.3 扫描与补拍策略

优先方案是“有重叠的扫描 + 边缘目标按需居中补拍”。若允许调整采集，先以 10%～20% 重叠作为配准试验起点；该范围不是保证每个 1.5 mm 克隆完整入镜的条件。20% 对应 0.644 mm 重叠、2.576 mm 步长；规则二维网格中图像数量约为零重叠的 1.56 倍，圆孔路径实际数量需由规划器计算。

若希望靠规则扫描保证直径 D 的近圆目标至少在某一张图完整出现，每轴需满足 `步长 <= FOV - D`。D=1.5 mm、FOV=3.22 mm 时，重叠率需至少约 46.6%；目标外还留 0.1 mm/侧余量时约 52.8%。这是理想规则网格内部的几何条件，不覆盖圆孔边界、路径裁切及定位误差。因此没有必要为了跨图问题一律把整孔扫描改为 50%以上重叠；优先评估定点补拍的时间成本。

既有零重叠数据仍可依据台位和边缘轮廓提出关联假设，但不能保证身份正确。对跨两图/四图交界且无法确认的克隆，使用全局范围规划一次 4x 居中补拍；1.5 mm 目标在 3.22 mm 视野内通常有容纳余量。补拍需验证候选确实匹配、轮廓完整且无孔壁遮挡；不完整则保留复核或继续获取邻域，不机械地强行接受一次补拍。

补拍居中位置可来自全局范围，但最终挑取点必须在完整确认的可用掩膜内重新计算；不能使用各图残片中心的平均值作为挑取点。真实孔壁遮挡不能通过图像拼接恢复不可见信息。

### 7.4 导出和执行必须服从全局结果

新增 `global_instances.py` 负责关联、融合与全局状态；`clone_dedupe.py` 保留完整实例的既有逻辑并接入新关联结果。`pickable_result.py` 改成先检查全局实例 `status == pickable`，再选择适合定位的观测，不再“组内有一个 true 就导出”。

扫描观察结果可以增量更新，但未解决的边缘实例不得进入自动挑取队列。以一次扫描运行中的稳定实例 ID 去重，补拍更新版本；相邻图或补拍出现新证据时使旧挑取授权失效。挑取前核对最新全局状态，单个全局实例最多派发一次；跨扫描批次身份匹配另行处理，不能直接复用按排序产生的 G001 等编号。

新增验收：

1. 正常 1.5 mm 克隆跨左右两图/四图交界，最终计数一次、仅产生一个挑取目标。
2. 同一克隆图 A 仅见正常区域、图 B 见大块过度生长区域，最终不产生挑取记录。
3. 大块暗团本身跨图，各片面积偏小，融合后仍识别并禁止挑取，不能被片段最小面积过滤丢失。
4. 正常克隆与独立暗团紧邻且跨图，不能串联为一个实例，也不能让暗团否决独立正常克隆。
5. 图像配准不可靠、无重叠且身份多解、真实孔壁遮挡，进入补拍/复核，不重复挑取或强行补全。
6. 挑取输出已生成后收到可信的过度生长证据，旧记录失效；补拍和扫描图不能产生两次派发。
