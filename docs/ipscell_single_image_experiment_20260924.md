## 实际改动

- `vision/experiments/single_image_rules.py`：独立单图分析函数 `analyze`，显式传入 FOV，仅使用 NumPy/OpenCV，无生产注册入口。
- `tools/review_ipscell_single_image.py`：执行原有默认规则 CPU 基线及实验版，保存每张图的原图预览、轮廓图、JSON、支撑/种子/暗区/低可见区掩膜，并生成 HTML 复核页面。
- `tests/test_single_image_experiment.py`：验证阴影负样本、稀疏点负样本、1.5 mm 目标、尺寸缩放一致性、大暗核及其外圈排除、小暗斑容忍、邻近独立目标保留和边缘候选保留。

试验输出一律 `is_pickable=false`、`requires_human_validation=true`。绿色是正常纹理候选；红色是规则推测的过度生长；橙色是纹理/形状/暗区不确定候选。当前没有任何试验结果直接进入挑取流程。

## 算法调整与参数

1. **物理尺度统一。** 按完整 3.22×3.22 mm FOV，使用约 3.145 μm/像素的工作网格，实际约 1024×1024；尺寸和窗口从物理单位换算，不将 1.5 mm 设为面积上限。图像若经过裁剪或 FOV 不同需改传正确值。
2. **取消全图/ROI 相互漂移的背景阈值。** 改为同一工作网格上的细节活动与局部占有率，种子、生长、边界处理共用这一证据，不再在每个 ROI 重新取第 40 百分位当背景。当前轮廓是工作网格分割后映射回原图，尚非原生 5120 像素精细贴边。
3. **暗区独立提取。** 计算平滑图的局部上包络与暗残差，分别保留暗区和低可见区；不再因为绝对灰度暗而补入正常前景。该近似不是已标定的照明场，不宣称能够完整区分孔壁阴影与细胞暗区。
4. **分开相连区域。** 通过稳定内部核心和标记控制分水岭分配支撑区域，恢复图 A1 上下区域的分离。大暗核单独作为证据，周围纹理环若与大暗核有包围/较大边界关联，也标为过度生长，防止只把黑心删除却保留绿色外圈。
5. **不确定候选保留供复核。** 小或形状不规则的纹理块不再静默消失；孔边暗区无法确认时保留 `dark_edge_review`。图像边缘目标记录截断及尺寸下界，本次不进一步做跨图处理。

## 未解决的限制

- 孔边几何和空孔参考缺失，目前仅用亮度、局部暗残差与边缘信息作近似；接触边界的大暗团和阴影可能无法可靠区分。
- 一些轮廓仍会包含细桥、邻近散点，或把稀疏大区域分成多个橙色候选；目前优先供人复核，不强行自动合并。
- 没有原生分辨率的边界再细化，轮廓可能存在约工作网格尺度的偏差。
- 本批图像用于开发调试，不能作为独立泛化验证集；上线前还需补充用户认可的目标/排除区与独立样本。
- 当前每张 CPU 实验检测约 3.9～4.6 s，大窗口暗区计算较慢；记录为单次粗略耗时，并且最终归档运行与回归检查有并行执行，不能作为正式性能基准。未做 GPU 优化。

## 用户复核方式

打开 HTML，点击图片放大，按编号判断“正确 / 误检，应删除 / 应保留为正常克隆 / 应判为过度生长 / 边界需修改”，并在每张图下描述漏检位置。点击“导出复核意见 JSON”保存结果；页面刷新前应先导出。
